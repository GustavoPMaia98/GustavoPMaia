A single entry on the vertical timeline (education, experience, publications) — a cyan node dot on a gradient rail beside a frosted card.

```jsx
<TimelineItem logo="assets/logos/nasa.png" title="NASA Goddard — Astrobiology Lab" meta="Nov 2024 · Research stay">
  HPLC–MS analysis of extraterrestrial organics.
</TimelineItem>
<TimelineItem title="FCT Doctoral Grant" meta="2023" last />
```

Stack several inside a container. `logo` is optional; set `last` on the final entry to trim the trailing rail. Hover lifts the card + cyan border.
