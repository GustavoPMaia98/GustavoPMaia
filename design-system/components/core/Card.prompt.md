Frosted-glass content surface — the base container for everything in the system. Translucent over the starfield, hairline border, soft shadow.

```jsx
<Card>
  <h3>Mechanochemical Reactivity of Ribonucleosides</h3>
  <p>Applied Sciences · 2025</p>
</Card>

<Card interactive padding={16}>Clickable timeline entry…</Card>
```

Set `interactive` for clickable cards (lightens + cyan border + 2px lift on hover). `padding` defaults to 24px; pass `style` to override. Radius is always 18px (`--radius-lg`).
